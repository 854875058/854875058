## 关于我

我关注如何把大模型、多模态数据、检索系统、任务调度和自动化工具结合起来，做成可运行、可复用、可维护的系统。

近期主要实践方向包括 AI 数据集处理算子、RAG、Agent、OCR、向量检索、知识图谱、文档解析和企业级 AI 应用原型。日常工作中主要写 Python，也会参与后端服务集成、接口联调和一些前端页面适配。

- RAG、Agent、Function Calling 与工具编排
